# SafeLoop 第一版页面清单

## 1. 页面总览
第一版重点实现“设备管理 + 点检执行 + 异常确认 + 隐患闭环”的核心业务闭环，页面设计以便于演示和面试追问为主。

| 页面名称 | 使用角色 | 页面目的 | 核心内容 | 核心操作 |
|---|---|---|---|---|
| 登录页 | 全部角色 | 统一进入系统 | 登录入口、角色切换提示 | 登录、退出 |
| 首页看板 | 全部角色 | 快速掌握整体状态 | 待办任务、超期任务、隐患统计、近期异常 | 查看统计、跳转详情 |
| 设备台账页 | EHS 管理员、系统管理员 | 管理设备基础信息 | 设备列表、设备状态、责任人、类别 | 新增设备、筛选、编辑 |
| 设备详情页 | EHS 管理员、设备责任人 | 查看单台设备全貌 | 基础信息、点检记录、异常记录、隐患历史、一物一码 | 查看详情、修改基础信息 |
| 一物一码页 | EHS 管理员、检查人员 | 便于现场识别设备 | 设备二维码信息、设备简要信息 | 扫码识别、查看设备信息 |
| 点检任务列表页 | EHS 管理员、检查人员 | 查看和管理点检任务 | 任务列表、截止时间、执行状态 | 查看、开始执行 |
| 移动点检录入页 | 检查人员 | 现场执行点检 | 点检项、检查结果、照片上传、异常标记 | 提交点检记录 |
| 异常上报页 | 检查人员、设备责任人 | 提交异常信息 | 异常描述、位置、影响、照片 | 保存草稿、提交异常 |
| 异常确认页 | EHS 管理员 | 将异常确认为隐患或一般异常 | 异常详情、风险等级、责任人、整改期限 | 确认隐患、标记一般异常、驳回 |
| 隐患列表页 | EHS 管理员、设备责任人 | 管理隐患闭环 | 隐患状态、责任人、截止时间、级别 | 筛选、查看详情 |
| 隐患详情页 | EHS 管理员、设备责任人 | 查看隐患处理全过程 | 隐患描述、整改记录、复查记录、附件 | 分派、查看记录、复查 |
| 整改执行页 | 设备责任人 | 完成整改动作 | 整改说明、整改措施、附件 | 提交整改记录 |
| 复查页 | EHS 管理员 | 确认整改是否合格 | 整改内容、复查结论、通过/不通过 | 通过、驳回 |
| 超期提醒页 | EHS 管理员、设备责任人 | 聚焦逾期任务 | 超期点检、超期整改、提醒信息 | 查看并处理 |
| 用户与权限页 | 系统管理员 | 管理角色和人员 | 用户列表、角色分配、权限设置 | 新增用户、修改角色 |

## 2. 页面优先级建议
### P0（第一版必须有）
- 登录页
- 首页看板
- 设备台账页
- 设备详情页
- 一物一码页
- 点检任务列表页
- 移动点检录入页
- 异常上报页
- 异常确认页
- 隐患列表页
- 隐患详情页
- 整改执行页
- 复查页

### P1（第一版建议补齐）
- 超期提醒页
- 用户与权限页

## 3. 业务约束
- 第一版不支持批量点检和批量整改。
- 移动点检采用响应式页面，不单独开发两套页面。
- 看板根据角色限制数据范围。

## 4. 待确认事项
- 看板是否需要按设备区域、设备类别或风险等级进行分组展示？
- 异常确认页是否需要补充“附件查看”与“历史记录对比”功能？
