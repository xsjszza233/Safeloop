# SafeLoop 用户角色与权限设计

## 1. 角色定位
系统第一版拟设计四类角色，分别覆盖设备管理、点检执行、异常确认、隐患整改和系统维护场景。

## 2. 角色说明
### 2.1 系统管理员
负责系统的基础配置与账号管理，确保平台正常运行；不承担日常隐患审批和关闭。

### 2.2 EHS 管理员
负责异常确认、隐患分派、整改复查、关闭隐患和看板管理，是业务流程的核心执行者。

### 2.3 检查人员
负责执行设备点检任务，提交点检记录并上报异常；不能确定最终风险等级、责任人和整改期限。

### 2.4 设备责任人
负责自己管辖设备相关的整改执行，查看本设备相关记录，并提交整改记录；不能修改原始检查记录、降低风险等级、删除记录或自行关闭隐患。

## 4. 角色边界说明
- 系统管理员聚焦“系统维持”和账号配置，不承担日常隐患审批和关闭。
- EHS 管理员是业务流程的主控角色，负责把异常转为正式隐患并推动闭环。
- 检查人员强调“发现问题”和“录入现场结果”，不负责最终风险判定和整改期限设定。
- 设备责任人主要承担“整改执行”和“整改反馈”，不能改动原始检查记录或自行关闭隐患。
