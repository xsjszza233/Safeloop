# SafeLoop 用户角色与权限设计

> 当前版本以本页“角色模型（当前）”为准。文末保留的早期四角色说明仅用于追溯，不作为当前权限模型或模拟数据的依据。

## 角色模型（当前）

SafeLoop 面向研发中心的 EHS 场景，将专职 EHS 管理职责与部门兼职安全联络职责明确区分。异常审核、隐患确认、风险定级、复查和关闭均由专职 EHS 管理员承担；部门 EHS Coordinator 只在本部门范围内协助日常安全管理。

### 1. 系统管理员

负责账号、角色、权限和系统技术配置，不参与异常审核、隐患确认、复查或关闭等业务决策。

### 2. EHS管理员（专职 EHS 人员）

企业安全专业管理人员，负责异常审核与隐患闭环管理。可查看全部设备、异常和隐患；审核异常并决定是否形成隐患；确定隐患等级；指定整改责任人；执行 EHS 复查并关闭隐患。

当前模拟数据中，陈小安和王宁为专职 EHS管理员。隐患确认人员与复查人员仅使用此类人员。

### 3. 部门EHS Coordinator（兼职安全联络人）

由研发部门内部人员兼任，负责本部门安全联络与日常协助。可查看本部门设备，协助执行点检、提交异常、跟踪整改进展并配合 EHS 管理；不能确认正式隐患、修改隐患等级或关闭隐患。

当前模拟数据中的一层实验组、分析测试组、材料研发组、化学与工艺组 Coordinator 均属于此角色。该角色不出现在隐患确认和 EHS 复查记录中。

### 4. 设备责任人

实际使用或管理设备的人员。可查看本人负责设备及相关点检记录，接收整改任务并提交整改措施；不能审核异常或确认隐患。

### 5. Facility工程师

负责配电设施、消防设施、电梯和其他公辅设备。可查看负责设施，执行维护和整改；不承担研发部门设备的普通点检职责，也不承担隐患确认或关闭职责。

### 6. 点检执行人员

按已分配任务执行现场点检、提交点检结果和异常。该角色可以由部门EHS Coordinator、实验室管理人员或 Facility 点检协调人员承担，但角色本身不赋予异常审核、隐患确认、风险定级、复查或关闭权限。

## 模拟人员数据约定

- 部门实验区域的点检人员池使用对应部门的兼职 Coordinator，不跨研发团队安排普通点检。
- Facility 公辅设施使用 Facility 工程师作为责任人、Facility 点检协调人员作为执行人员；该类人员不使用“EHS Coordinator”标签。
- EHS管理员仅承担异常审核、隐患确认、复查和关闭等专职 EHS 职责，不作为普通设备点检人员。

## 附录：历史版本（已废止）

### 旧版角色定位
系统第一版拟设计四类角色，分别覆盖设备管理、点检执行、异常确认、隐患整改和系统维护场景。

## 2. 角色说明
### 2.1 系统管理员
负责系统的基础配置与账号管理，确保平台正常运行；不承担日常隐患审批和关闭。

### 2.2 EHS 管理员
负责异常确认、隐患分派、整改复查、关闭隐患和看板管理，是业务流程的核心执行者。

### 2.3 检查人员
负责执行设备点检任务，提交点检记录并上报异常；不能确定最终风险等级、责任人和整改期限。

### 2.4 设备责任人
负责自己管辖设备相关的整改执行，查看本设备相关记录，并提交整改记录；不能修改原始检查记录、降低风险等级、删除记录或自行关闭隐患。

## 4. 角色边界说明
- 系统管理员聚焦“系统维持”和账号配置，不承担日常隐患审批和关闭。
- EHS 管理员是业务流程的主控角色，负责把异常转为正式隐患并推动闭环。
- 检查人员强调“发现问题”和“录入现场结果”，不负责最终风险判定和整改期限设定。
- 设备责任人主要承担“整改执行”和“整改反馈”，不能改动原始检查记录或自行关闭隐患。
