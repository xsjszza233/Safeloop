# SafeLoop 设备台账模块设计（第一版）

## 1. 模块目标

设备台账模块用于维护制造企业、研发中心和实验室内需要纳入 EHS 管理范围的设备基础信息，并为点检任务、异常上报、隐患整改与历史追溯提供统一的设备主数据。

第一版以学习和展示为目的，全部设备及人员信息均为虚构模拟数据，不引用或推导任何具体法规要求。

## 2. 设备类别

第一版使用以下五类模拟设备：

| 设备类别 | 典型使用场景 | 管理关注点 |
| --- | --- | --- |
| 酸碱柜 | 实验室试剂存储区 | 柜体完好、分类存放、泄漏与通风情况 |
| 通风橱 | 化学实验室 | 面风速、柜体状态、排风与操作区域状况 |
| 配电箱 | 车间、实验室、公共区域 | 箱体封闭、标识、接地与异常发热迹象 |
| 消防器材 | 车间、办公区、实验室、仓储区 | 配置位置、外观、压力状态与有效状态 |
| 电梯 | 办公楼、研发楼、厂区公共区域 | 运行状态、警示标识、维保与异常上报 |

设备类别用于关联默认点检模板和默认点检周期；同一类别的单台设备可以在设备级别覆盖这些默认设置。

## 3. 设备基础字段

| 字段 | 建议类型 | 业务含义 |
| --- | --- | --- |
| 设备 ID | 系统生成的唯一标识 | 用于数据关联、接口预留和内部追溯；不建议由业务人员手工修改。 |
| 设备编号 | 文本，唯一 | 面向现场和管理人员的识别编号，例如 `LAB-FH-001`。 |
| 设备名称 | 文本 | 设备的常用名称，例如“有机实验室通风橱”。 |
| 设备类别 | 枚举/关联字段 | 取值为第一版定义的五类模拟设备之一，用于分类统计与默认规则匹配。 |
| 所属部门 | 文本或部门关联 | 负责使用或管理该设备的部门，例如研发部、制造部或行政部。 |
| 所在区域 | 文本 | 设备所在的较大物理区域，例如研发楼、装配车间或仓储区。 |
| 具体位置 | 文本 | 设备的精确位置，例如“研发楼 3 层化学实验室东侧”。 |
| 责任人 | 用户关联 | 设备日常管理或整改执行的第一责任人；不等同于每次点检的检查人员。 |
| 设备状态 | 枚举 | 标识设备当前可用及管理状态：在用、停用、维修中、报废。 |
| 状态变更日期 | 日期时间 | 最近一次设备状态变更的生效时间，例如恢复在用、转维修中或报废的日期。 |
| 状态变更记录 | 操作记录关联 | 保存状态变更前后值、操作人、变更日期、原因及对未完成点检任务的处理决定。 |
| 设备风险等级 | 枚举 | 低、中、高；设备类别默认带入后，可由 EHS 管理员在设备级调整，用于看板聚合、筛选和点检关注度展示。 |
| 是否覆盖类别默认配置 | 布尔值/覆盖项集合 | 标识该设备是否覆盖类别默认风险等级、点检模板或点检周期，并记录具体被覆盖的配置项。 |
| 投用日期 | 日期 | 设备开始正式投入使用或纳入台账管理的日期。 |
| 默认点检周期 | 周期/只读展示 | 由设备类别带入的建议周期，用于说明类别规则来源。 |
| 实际点检周期 | 周期 | 当前设备实际采用的点检周期；未覆盖时与默认点检周期一致。 |
| 上次点检日期 | 日期 | 最近一条已完成点检记录对应的实际点检日期。 |
| 下次点检日期 | 日期 | 根据实际点检周期与上次点检日期计算或由任务计划生成的下一次目标日期。 |
| 关联点检模板 | 模板关联 | 当前设备执行点检任务时使用的点检模板，可继承类别默认模板或单独覆盖。 |
| 报废日期 | 日期 | 设备状态为报废时允许补充的归档信息。 |
| 报废原因 | 多行文本 | 设备状态为报废时允许补充的归档信息，用于说明退出使用的原因。 |
| 归档备注 | 多行文本 | 设备状态为报废时允许补充的归档信息。 |
| 设备说明 | 多行文本 | 补充设备用途、特殊操作要求或现场管理说明；不记录未经确认的法规结论。 |
| 创建时间 | 系统时间 | 台账记录首次创建的时间。 |
| 更新时间 | 系统时间 | 台账记录最近一次修改的时间。 |

## 4. 状态与规则

### 4.1 设备状态

| 状态 | 含义 | 点检任务规则 | 页面展示建议 |
| --- | --- | --- | --- |
| 在用 | 设备正在正常投入使用 | 按实际点检周期持续生成点检任务。停用或维修中恢复为在用时，默认从恢复日期重新计算下一次点检日期；EHS 管理员可选择立即生成恢复后点检任务。 | 绿色或常规状态标签。 |
| 停用 | 设备暂不使用，但仍保留在台账中 | 不生成新的常规点检任务；暂停新增逾期判断，但保留历史逾期记录。 | 显示“停用”，保留历史点检、异常和隐患。 |
| 维修中 | 设备处于维修或故障处理阶段 | 暂停常规点检任务与新增逾期判断，但保留历史逾期记录。恢复在用前必须由 EHS 管理员确认是否需要维修后专项点检；第一版不统一强制创建。 | 显示“维修中”，并在设备详情突出当前状态与关联异常/隐患。 |
| 报废 | 设备永久退出使用 | 不再生成新的点检任务，也不再计算逾期。核心业务字段和历史记录只读，仅允许补充报废日期、报废原因和归档备注。 | 显示“报废”，不允许作为正常点检任务的候选设备。 |

### 4.2 风险等级与边界

| 等级 | 业务含义 | 使用方式 |
| --- | --- | --- |
| 低 | 常规风险、常规点检关注度 | 用于筛选、看板统计和列表标签。 |
| 中 | 需要较高频次关注或存在一定后果的设备 | 用于筛选、看板统计和点检任务优先级提示。 |
| 高 | 需要重点关注的设备 | 用于筛选、看板突出显示和后续点检计划配置参考。 |

设备类别应维护默认设备风险等级；EHS 管理员可以在单台设备级调整，设备责任人只能提出调整建议，不能直接修改等级。

必须明确区分以下三类等级，避免在页面、数据和流程中混用：

| 等级名称 | 所属对象 | 含义与使用边界 |
| --- | --- | --- |
| 设备风险等级 | 设备台账 | 设备的持续性管理关注标签，用于设备筛选、看板统计和点检关注度。 |
| 异常建议等级 | 异常记录 | 检查人员或设备责任人上报异常时可提出的现场建议，不构成正式隐患等级。 |
| 隐患风险等级 | 隐患记录 | EHS 管理员确认异常形成隐患时确定的正式整改闭环等级，用于整改期限、分派和复查管理。 |

以上等级均为内部 EHS 管理标签，不替代风险评估、检验结论或任何法定判定。

### 4.3 点检周期规则

- 设备类别默认点检模板和默认点检周期由 EHS 管理员维护；系统管理员只负责技术和权限配置。
- 单台设备可以覆盖类别默认点检周期和默认点检模板，并通过“是否覆盖类别默认配置”字段记录覆盖情况。
- 设备详情应同时展示“默认点检周期”和“实际点检周期”，以及默认模板、实际模板与覆盖标识，便于识别设备级覆盖。
- 已生成但未完成的点检任务不因周期变更而自动删除；后续任务按新周期生成。
- 设备状态变更时，已生成但未完成的点检任务不得自动删除。EHS 管理员应选择保留、取消或转为专项点检，并将处理结果写入状态变更记录和操作日志。

### 4.4 逾期判断规则

- 在用设备按下次点检日期正常计算是否逾期未检。
- 停用和维修中设备暂停新增逾期判断，但已经形成的历史逾期记录继续保留。
- 报废设备不再计算逾期。
- “已逾期”是时间标记，不是设备主状态。

## 5. 页面需求

### 5.1 设备台账列表页

页面目标是让 EHS 管理员和系统管理员快速定位设备状态、责任人、点检计划与风险信息。

建议列表字段：

- 设备编号、设备名称、设备类别
- 所属部门、所在区域、具体位置
- 责任人
- 设备状态、风险等级
- 实际点检周期
- 上次点检日期、下次点检日期
- 是否逾期未检

建议操作：查看设备详情、新增设备、编辑设备基础信息、调整设备状态；第一版不支持批量修改或批量点检。

### 5.2 设备详情页

页面目标是汇总单台设备的主数据、点检设置和关联业务过程，支持设备全生命周期内的可追溯查看。

建议操作：查看基础信息、调整基础信息（具备权限时）、查看点检记录、查看相关异常和隐患。设备详情页不直接把异常视为隐患，仍遵循“先提交异常、由 EHS 确认后形成隐患”的流程。

## 6. 列表筛选条件

设备台账列表至少应支持以下筛选：

| 筛选条件 | 说明 |
| --- | --- |
| 关键词 | 按设备编号、设备名称、具体位置或责任人进行模糊查询。 |
| 设备类别 | 在酸碱柜、通风橱、配电箱、消防器材、电梯中筛选。 |
| 所属部门 | 查看特定部门管理或使用的设备。 |
| 设备状态 | 在用、停用、维修中、报废。 |
| 风险等级 | 低、中、高。 |
| 是否逾期未检 | 在用设备按下次点检日期与当前日期计算；停用、维修中暂停新增判断并保留历史记录，报废设备不再计算。 |

## 7. 设备详情页信息区

设备详情页至少包含以下信息区：

| 信息区 | 内容 |
| --- | --- |
| 基本信息 | 设备编号、名称、类别、所属部门、区域、具体位置、责任人、投用日期、设备说明。 |
| 点检设置 | 默认点检周期、实际点检周期、默认模板、关联点检模板、是否覆盖类别默认配置、上次点检日期、下次点检日期。 |
| 当前状态 | 设备状态、状态变更日期、设备风险等级、是否逾期未检及必要的状态说明。 |
| 历史点检 | 关联的点检任务和点检记录，包括执行人、实际点检日期、结果和时间标记。 |
| 相关异常 | 该设备关联的异常记录，展示异常状态；未确认的异常不能作为隐患展示。 |
| 相关隐患 | 经 EHS 管理员确认形成的隐患及其整改、复查和关闭状态。 |
| 操作记录 | 设备创建、基础信息变更、状态变更、周期覆盖等操作的时间、操作人和变更摘要。 |

## 8. 第一版暂不开发

- 真实设备接口或现场实时监测数据接入
- ERP、MES、CMMS 等系统集成
- 法定检验管理、法规条款匹配或合规结论生成
- 设备采购、资产折旧和财务管理
- 预测性维护与故障预测
- 真实二维码生成与扫描

## 9. 仍需确认的业务规则

当前没有已识别且影响第一版设备台账实现的未确认规则。第 4 节已正式确定设备恢复、维修后专项点检、报废归档、风险等级权限、类别默认配置、未完成点检任务处理和逾期判断规则。
